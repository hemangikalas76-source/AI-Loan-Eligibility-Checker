## 🌟 About The Project

**CrediAI** is an AI-powered loan eligibility checker designed to help users understand their loan approval chances through intelligent financial analysis.

The application evaluates important financial parameters such as:

- 💰 Monthly Income
- 💼 Employment Type
- 📊 Credit Score
- 💳 Existing Debts
- 🏦 Liquid Assets
- 📝 Requested Loan Amount

Based on these financial details, CrediAI generates an estimated eligibility score and provides insights to help users make smarter borrowing decisions.

## ✨ Key Features

- 🎯 **Loan Eligibility Prediction** – Estimates loan approval probability based on financial information.
- 💰 **Financial Profile Analysis** – Evaluates income, employment, assets, and existing liabilities.
- 📊 **Credit Score Evaluation** – Analyzes CIBIL/FICO credit scores.
- 🧮 **EMI Calculator** – Estimates monthly installments and interest rates.
- 🔄 **Interactive Loan Simulator** – Adjusts loan amounts and tenure to explore different scenarios.
- 🛡️ **Risk Assessment** – Provides credit history, income stability, and debt-service risk breakdowns.
- 🤖 **AI Financial Advisor** – Suggests ways to improve loan eligibility.
- 📅 **Amortization Schedule** – Displays monthly principal, interest, EMI, and remaining balance.
- 📥 **CSV Export** – Exports loan repayment information.

## 🔄 How It Works

1. 👤 Enter personal and employment details.
2. 💵 Provide income and financial information.
3. 📊 Enter credit score and existing debt details.
4. 📝 Select requested loan amount and tenure.
5. ⚡ Analyze the financial profile.
6. 🎯 View the estimated loan eligibility score.
7. 🤖 Get personalized financial recommendations.
